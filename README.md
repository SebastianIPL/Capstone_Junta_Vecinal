# Sistema Integral para Unidad Territorial (Junta de Vecinos)

Plataforma web para la administración comunitaria, gobernanza digital y emisión de certificados territoriales con verificación QR.

## 🚀 Stack Tecnológico
- **Backend:** Django 6.x / Python 3.13
- **Frontend:** Tailwind CSS / HTML5 semántico
- **Base de Datos:** PostgreSQL 16 (Producción) / SQLite (Dev)
- **Librerías:** Pillow (procesamiento multimedia), ReportLab (PDFs en memoria con QR)
- **Contenerización:** Docker & Docker Compose
